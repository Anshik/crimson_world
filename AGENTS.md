# Browser QA policy

- Все новые проверки браузерного интерфейса запускаются в отдельном headless-профиле, без видимых окон, перехвата фокуса и использования пользовательских профилей.
- Firefox и Vivaldi не запускать и не трогать.
- Safari запускать только после отдельного явного согласования на конкретную проверку. Исторические Safari-результаты в документации не являются разрешением на новые запуски.
- До фактического успешного прогона не заявлять прохождение headless QA.
