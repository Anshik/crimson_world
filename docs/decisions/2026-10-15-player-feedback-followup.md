# Уточнения после пробной игры: движение, кубик и снаряжение

Дата: 15 октября 2026 года. Статус: фиксация прямой обратной связи владельца и границ допущений реализации.

Уточняет [предыдущую запись](2026-10-15-dice-and-city-places.md), где ещё указаны автоматическое закрытие кубика и прежняя клетка лавки. Документ создан при сверке источников, чтобы не смешивать пожелания владельца с самостоятельно выбранными числами.

## Прямые указания

| Указание владельца | Действующее поведение |
| --- | --- |
| Повторное нажатие выбранного направления должно бросать кубик | Второе нажатие запускает ход. |
| Окно броска слишком быстро пропадает; закрывать кнопкой «Дальше», нажатием на окно или в другом месте | Результат остаётся до закрытия; после окончания анимации доступны эти способы. |
| Не утраивать число броска и не писать о сгорании шагов | Число и следствие сформулированы раздельно; потеря остатка не сопровождается лишним сообщением. Само правило остановки сохранено. |
| Выбранный маршрут уже известен, на перекрёстке можно сразу бросать | Кратчайший путь продолжается автоматически; игрок может изменить направление. |
| Доставка сети не должна заканчивать игру | Окно награды закрывается, то же сохранение продолжает партию. |
| Лавка должна срабатывать перед входом, а не на перекрёстке | Услуги перенесены с J03 на ближайший вход U06. |
| В лавке можно продавать товары | Добавлены продажи; конкретные цены и отсутствие архивной пробы интереса торговца выбраны при реализации. |
| Проверить извещения и сделать по документации | Взяты шесть архивных сюжетов. Сам отбор и сокращение ветвей не следует считать отдельно утверждёнными; [аудит](../rules/CONFORMANCE.md). |
| Проверить дневного разбойника, показать статы для выбора боя/бегства | Показаны характеристики; днём можно пройти или вызвать на бой. Ночное нападение сохранено. |
| Проверить «О» и сдачу трофеев | Источники связывают приём отдельных трофеев с Заказом; значение «О» не установлено, действие дому не назначено. |
| Показать персонажа, слоты и свойства вещей при наведении | Добавлен лист с фигурой, слотами и подсказками. |

## Что пока не является отдельным принятым правилом

Вопрос «менять оружие во время боёвки — потеря раунда?» запустил исследование. В источниках общей нормы не найдено. Реализованная цена в одно действие героя, сохранение запасного меча и разложение фиксированных показателей на «базу + доспех» — допущения исполнителя. Они описаны в [COMBAT_AND_RACES.md](../COMBAT_AND_RACES.md), но факт описания не означает отдельного подтверждения владельцем. Их дальнейшая судьба вынесена в [пул задач](../rules/BACKLOG.md).

15 октября владелец также поручил повторно разобрать документы, проверять соответствие с исключением явно согласованных изменений и перенести обработанные оригиналы на Чердак. Поэтому текущая реорганизация создаёт поисковые копии и журнал контрольных сумм, сохраняя исторические версии и различая указанные выше статусы.
