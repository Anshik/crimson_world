# Статическое приложение для фазы прогулки

Дата: 13 октября 2026 года. Статус: техническое решение, реализованное при переходе к следующей фазе по поручению владельца. Конкретные библиотеки отдельно владельцем не выбирались.

## Контекст

Для Товилиса приняты статическое браузерное приложение и локальное сохранение; готова разметка карты. Следующая фаза должна позволить двигать гнома по этим данным и проверять правила в Safari без установки игрового сервера. Полный заказ, встречи и бой реализуются последовательно после перемещения.

## Рассмотренные варианты

Можно подключить клиентский фреймворк со сборкой либо использовать обычные HTML, CSS и JavaScript. Canvas или игровой движок потребовали бы отдельно реализовать доступные кнопки и работу с уже готовой SVG-разметкой. Для текущего объёма выбран вариант без внешних зависимостей.

## Решение

Создана отдельная страница `game/index.html`. Просмотрщик разметки сохраняет свою роль. Карта берётся из принятого PNG; фигурка и подсветки накладываются через SVG. Генератор разметки выпускает один и тот же набор данных в JSON и обычный JavaScript для открытия через `file://`.

Правила вынесены в отдельный модуль, доступный браузеру и встроенному тестовому раннеру Node.js. Он принимает состояние и явный источник броска, возвращает новое состояние, не обращаясь к DOM или хранилищу. Интерфейс сначала записывает целое состояние в `localStorage`, затем показывает анимацию. Неудачная запись не разрешает продолжить неподтверждённый ход.

Фаза прогулки имеет собственную версию сохранения и явную границу: полноценные извещения включены; встречи пропускаются с пояснением, здания пока описывают будущие услуги. Это не меняет утверждённую спецификацию полной первой партии. Готовый гном создан отдельным прозрачным изображением, исходная карта остаётся неизменной.

## Последствия

Прогулка запускается локальным файлом и проверяется без установки пакетов. Чистые правила позволяют воспроизводить результаты и затем расширить состояние встречей и боем. Миграция сохранений прогулки в полную партию, проверка физических мобильных устройств и многопользовательские транзакции не входят в это решение. Текущий выбор не задаёт стек будущего общего мира.
